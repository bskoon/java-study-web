JVM의 메모리 영역은 모든 스레드가 공유하는 영역(Method, Heap)과 각 스레드 고유의 영역(Stack, PC, Native Stack)으로 나뉩니다.

현재 활성화된 스레드의 실행 흐름과 스택 프레임 상태를 추적합니다.
공유 영역
Method Area (메서드 영역)
클래스 로더가 읽어들인 클래스 메타데이터, 상수풀, static 변수 등이 로드됩니다.
class Main { ... }
class User { ... }
공유 영역
Heap Area (힙 영역)
런타임에 동적으로 생성된 인스턴스 객체들이 들어옵니다. GC가 주기적으로 수거합니다.
User@4a23 (age: 1)
String@2f12 ("Hello")
스레드 전용 (Thread-1)
JVM Stack (스택 영역)
메서드 호출 시 생성되는 스택 프레임이 쌓이며, 지역 변수들이 관리됩니다.
스레드 전용 (Thread-1)
PC Register (프로그램 카운터)
현재 스레드가 실행 중인 JVM 명령의 주소를 가리킵니다.
PC: 0x00000000
스레드 전용 (Thread-1)
Native Method Stack
C, C++ 등 기계어로 작성된 네이티브 라이브러리를 위한 스택입니다.
[Idle]
